- **Compiler:** GCC
- **Editor:** Visual Studio Code

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/sahilpal1/C_language.git
   ```

2. Navigate to the project directory:

   ```bash
   cd C_language
   ```

3. Compile a C program:

   ```bash
   gcc main.c -o main
   ```

4. Run the program on Windows:

   ```bash
   .\main.exe
   ```
